# Contributing

Thanks for helping improve Colosseum Inspired UI Overhaul.

## Before opening an issue

- Confirm the issue occurs on the latest release.
- Note whether you are running Gen 1 or Gen 2.
- List other enabled UI, sprite, battle, or compatibility mods.
- Include a screenshot or short clip when the problem is visual.
- Include exact steps that reproduce crashes or broken navigation.

## Pull requests

Keep changes presentation-only unless a maintainer explicitly approves a broader scope. Do not alter battle state, save data, resolved sprite sources, or unrelated user settings.

Before submitting:

1. Validate `manifest.json`.
2. Confirm `main.lua` loads without syntax errors.
3. Test both Gen 1 and Gen 2 when shared UI code changes.
4. Confirm Menu Intro, mobile UI, and sprite-source compatibility remain intact.
5. Update `CHANGELOG.md` for user-visible changes.
